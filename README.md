# eduquizlk-legal — hosted legal pages for EDU Quiz Lanka

Static Privacy Policy + Terms of Service for store listings, AdMob UMP, and GDPR.
Source of truth for the TEXT is the app repo: `EDURank\lib\legal-content.ts`.
**If either side changes, update both** (in-app viewer + these pages).

## Publish with GitHub Pages (one-time, ~10 min, free)

1. GitHub Desktop → File → New repository…
   - Name: `eduquizlk-legal`
   - Local path: `E:\EDU LABS\projects\edu-quiz-lk\` (it will use this folder)
   - Do NOT initialise with a README (this one exists)
2. Commit all files → Publish repository → UNTICK "Keep this code private" (Pages needs public on free plan).
3. On github.com → repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
4. After ~1 minute the pages are live at:
   - `https://<your-username>.github.io/eduquizlk-legal/privacy.html`
   - `https://<your-username>.github.io/eduquizlk-legal/terms.html`

## Where to paste the URLs

- Google Play Console → App content → Privacy policy → privacy URL
- App Store Connect → App Privacy → Privacy Policy URL
- AdMob console → Privacy & messaging → GDPR message setup
- (later) custom domain eduquizlk.com can be attached in repo Settings → Pages with zero content changes
